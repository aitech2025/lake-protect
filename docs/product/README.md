# GeoGuard Product Documentation

This folder contains the product-level requirements and the government data exchange contract.

- [Business Requirements & Product Requirements (BRD/PRD)](GEOGUARD-BRD-PRD.md) — product vision, business objectives, actors, workflows, functional/non-functional requirements, governance, acceptance criteria and phased roadmap.
- [Government Data Onboarding Specification](GOVERNMENT-DATA-ONBOARDING-SPEC.md) — department submission package, asset schema, geospatial formats/CRS, legal document index, validation rules and registration controls.
- [Requirements Traceability Matrix](GEOGUARD-RTM.md) — maps all 112 functional requirements to repository evidence, implementation status, gaps, dependencies, delivery increments and test expectations.
- [RTM CSV export](GEOGUARD-RTM.csv) — machine-readable matrix for spreadsheet review, filtering and backlog planning.

These documents describe the target product and proposed operating model. They do not imply that every capability is implemented or that government legal, data-sharing, procurement and operational approvals have been obtained.

## Change control

Update these documents through pull requests. Requirement IDs (FR-*) should remain stable once referenced by implementation plans, test cases or stakeholder decisions. Changes to scope, legal authority, data retention, asset identity or approval workflows require explicit review by the relevant product and government stakeholders.
